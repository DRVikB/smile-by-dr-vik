# Existing SlimSAM ONNX models

Model family: nielsr/slimsam-77-uniform. ONNX conversion: Xenova/slimsam-77-uniform.
License: Apache-2.0 (upstream model card: https://huggingface.co/Xenova/slimsam-77-uniform). LICENSE.txt retains the Apache license.

These quantized encoder/decoder files were already present before Macro Stage 2. Their bytes have not changed in this stage. They remain local, CPU/WASM, and lazy-loaded only for explicit segmentation refinement. The upstream model is a general segmentation model, not a clinically validated tooth segmentation system.
